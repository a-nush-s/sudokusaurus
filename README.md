Sudokusaurus is a dinosaur-themed sudoku game with a twist. After a certain number of inputs and a certain amount of time (depending on your difficulty), our dino friend will "eat" one of your numbers off the board! 
This game was made independently by myself. All assets were hand drawn and code was written with help from Claude Code. 
You can play this game using the Github-deployed page at https://a-nush-s.github.io/sudokusaurus/
